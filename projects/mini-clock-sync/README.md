# mini-clock-sync

两路各自自由运行的设备时钟，比率不是常数：固定比率转换迟早漂。
本库在线估计比率，稳定后冻结估计值做转换，并对转换结果给出漂移上界。

## 模型

同一事件在时钟 A（参考）和时钟 B 下的时间戳对 `(x, y)` 满足
`y = r·x + b + 噪声`，其中比率 `r` 随时间缓慢漂移。

- **在线估计**：滑动窗口（默认 600 对）上的最小二乘，每 `check_every`
  个事件做一次稳定性检查；斜率连续 `lock_checks` 次变化不超过
  `4·σ_r`（σ_r 为由残差推出的斜率标准误）即判定稳定并**锁定**，
  冻结 `r̂`、`b̂`。
- **转换**：锁定后 `x̂ = (y − b̂) / r̂`。
- **漂移上界**（A 时钟秒，`dt = x − x_lock`）：

  ```
  |x̂ − x_true| ≤ [ E0 + (4·σ_r + κ·T_w)·dt + ½·κ·dt² ] / r̂
  ```

  `E0` 为锁定时窗口内最大残差，`T_w` 为窗口时间跨度，
  `κ = 3 × 锁定前观测到的最大 |dr/dt|`。

## 验证

`make test` 生成三组 1 小时仿真长录音（每 0.5 s 一个对齐事件，
已知真值），报告锁定时间、比率估计误差、最终漂移与上界：

| 录音 | 漂移形态 | 估计误差 | 最终漂移 | 上界 |
|---|---|---|---|---|
| constant | 固定比率 +50 ppm，抖动 ±20 µs | ~0.02 ppm | ~0.07 ms | ~21 ms |
| linear-drift | 比率线性漂 2e-9/s（7.2 ppm/h） | ~0.3 ppm | ~11.5 ms | ~47 ms |
| random-walk | 比率随机游走 + 40 min 处 1 ppm 阶跃，抖动 ±100 µs | ~0.2 ppm | ~1.4 ms | ~73 ms |

上界在所有时刻均包住实际漂移（测试中断言）。constant 组上界偏松，
因为 κ 取自噪声下的最大观测速率，保守是上界应有的性质。
