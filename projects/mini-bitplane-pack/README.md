# mini-bitplane-pack

Packed 1/2/4/8bpp image row packer (C11, no deps) + 位平面↔像素交错原地互转。

构建与测试：`make test`；基准：`make bench`。

## 两种布局

- **像素交错（chunky）**：每像素 1 字节的颜色索引，共 `w*h` 字节。
- **位平面（planar，设备要求）**：`bpp` 个平面，平面 `p` 位于 `buf[p*ps, (p+1)*ps)`，
  `ps = ceil(w/8) * h`。像素 `(x,y)` 的第 `p` 位存放在平面 `p` 第 `y` 行第 `x` 位，
  字节内 MSB 优先。

`src/bitpack.*` 为原有连续位流打包路径（`pack_rows/unpack_rows`），行为不变；
`src/planar.*` 为新增的两种布局互转（`chunky_to_planar/planar_to_chunky`）。

## 尾部补位规则（宽度非 8 倍数）

每个平面按**行**对齐到字节：每行占 `ceil(w/8)` 字节，行末不足 8 位的尾部为补位。

- 交错 → 平面：补位恒写 **0**；
- 平面 → 交错：补位**忽略**，不产生像素；
- 往返一致性：交错 → 平面 → 交错恒逐字节一致；平面 → 交错 → 平面对**补位为 0
  的规范数据**逐字节一致，非零补位会被规范化为 0（`tests/test_planar.c` 中
  `padding_normalized` 与手工金样 `w=5 → 0xB0` 等均覆盖）。

## 错误码（三类，互不相同）

| 码 | 含义 |
|---|---|
| `BP_ERR_PLANES` (1) | 平面数/几何参数非法：`bpp` 不在 1..8，或 `w/h <= 0` |
| `BP_ERR_LENGTH` (2) | 长度不符：`buf_len < max(w*h, bpp*ps)`，或一个平面暂存分配失败 |
| `BP_ERR_RANGE`  (3) | 索引范围越界：像素值 `> (1<<bpp)-1` |

## 原地转换与额外内存

转换在同一个缓冲区完成（`buf_len >= max(w*h, bpp*ps)`），额外内存恰好**一个平面**
（`ps` 字节的 `scratch`，传 `NULL` 则内部 malloc/free，除此之外无堆分配）。

**为什么原地不破坏源数据**：设 `n = w*h`。交错→平面先把每像素 1 字节就地压缩为
每像素 `bpp` 位（收缩，写偏移 ≤ 读偏移），随后从高位平面起逐层"剥离"：提取当前
最高位平面到一个平面暂存，把剩余像素**就地重新打包**到更窄位宽，再把暂存拷入
平面槽位。不变量：源被压缩到每像素 `p` 位时占 `ceil(n*p/8) ≤ p*ps` 字节
（因 `ps ≥ n/8`），始终低于第 `p` 个平面槽位的起点 `p*ps`——未读的源与写入目标
区间恒不相交。平面→交错是同一不变量的反向运用（逐层扩张并合并，平面 `p` 先
移入暂存再扩张）。金丝雀测试（缓冲区与暂存两侧警戒字节）在 `make test` 中验证。
